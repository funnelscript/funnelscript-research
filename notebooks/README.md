# FunnelScript Engineering Notebooks

This directory contains executable notebooks and interactive playbooks detailing the mathematical foundations, system architectures, and simulation algorithms of FunnelScript.

## Available Notebooks

* [`executive_engineering_notebook.md`](executive_engineering_notebook.md): Complete, high-precision engineering playbook and knowledge graph synthesizing the core vision, Bayesian prior injection, 5-subsystem architecture, cross-industry language intersections (Terraform, Julia, Solidity), and verified hypothesis ledger.
* [`executive_engineering_notebook.ipynb`](executive_engineering_notebook.ipynb): Interactive, runnable Jupyter Notebook executing live demonstrations of synthetic agent tensor generation, Hill saturation kinetics, vectorized decision kernels, and mass conservation invariant verification on 100,000 agents.
